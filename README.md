# Flight Monitor releases

Public APK host for the private [airway](https://github.com/mumayank/airway) source repo.

## Download

**[Latest release](https://github.com/mumayank/flight-monitor-releases/releases/latest)**

Asset naming: `flight-monitor-v{versionName}-release.apk`

## Install

1. Download the signed APK on your phone.
2. Allow install from this source if prompted.
3. Unlock with family PIN (see private source docs).
4. Updates: same package + signing cert → in-place update (data kept).

## Privacy

Flight Monitor tracks one IndiGo flight number and date only. It does **not** collect IndiGo PNR, booking email, or surname.

## About

Family sideload app. Not on Play Store. Source remains private.
